# Entradas de Coco

Coco comparte el perfil activo de Lima. Para inicialización consulta [../lima/reference/intake.md](../lima/reference/intake.md) y [../lima/reference/first-run.md](../lima/reference/first-run.md); no mantiene un formulario paralelo.

## Campos propios

- `coco.data_contract`: protagonista, campos reales/opcionales y reglas de presentación comprobadas. Inspecciona código y documentos antes de preguntar. `none-yet` significa datos ilustrativos etiquetados, no permiso para inventar entidades.
- `coco.governance_scripts` y `coco.governance_policy`: rutas existentes y checks mecánicos del proyecto; declara faltantes sin crear una CLI imaginaria.
- Campos legacy de estándar documental son contexto; `.fruti/contracts/documentation.yaml` (raíz) pertenece a Mora y fija shell, secciones y orden.

Si falta un dato que cambia la experiencia, pide esa decisión concreta. Si solo falta una ruta o stack detectable, inspecciona. Si falta el contrato o aprobación F3 requerida por el siguiente rol, registra el bloqueo y no actives implementación dependiente. Consulta [profile-additions.md](profile-additions.md) para formatos compatibles.
